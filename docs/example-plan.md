# Greet CLI

## Goal
Create a zero-dependency Node.js CLI `greet.js` that prints a greeting (optionally shouted), plus `test.sh` that verifies all three behaviors and fails the build on mismatch.

## Context
- Repo is empty (not a git repo yet); no existing conventions to follow.
- Node.js only, no npm packages — use `process.argv` for args.
- `test.sh` must be bash, executable, use `node greet.js ...`, compare output via string equality, and `exit 1` (or any non-zero) if any case fails, `exit 0` if all pass.
- Args: first non-flag argument is `<name>`; `--shout` flag (in any position) uppercases the final string. `--shout` should not be treated as the name.

## Tasks

- [ ] T1: Implement greet.js
  - Files: `greet.js` (new)
  - Do: Write a Node script that:
    - Reads `process.argv.slice(2)`.
    - Detects `--shout` anywhere in the args and removes it from consideration.
    - Uses the first remaining arg as `<name>`, defaulting to `"world"` if none given.
    - Builds `Hello, <name>!`, uppercases it if `--shout` was present, then `console.log`s it.
    - Example implementation:
      ```js
      #!/usr/bin/env node
      const args = process.argv.slice(2);
      const shout = args.includes('--shout');
      const name = args.find(a => a !== '--shout') || 'world';
      let message = `Hello, ${name}!`;
      if (shout) message = message.toUpperCase();
      console.log(message);
      ```
  - Done when: running these manually all print the expected line:
    - `node greet.js` → `Hello, world!`
    - `node greet.js Alice` → `Hello, Alice!`
    - `node greet.js Alice --shout` → `HELLO, ALICE!`

- [ ] T2: Implement test.sh
  - Files: `test.sh` (new)
  - Do: Write a bash script (with `#!/usr/bin/env bash` and `set -e` for setup only, not for the comparisons) that:
    - Runs the three cases from T1, capturing output with `$(node greet.js ...)`.
    - Compares each captured output to the expected string.
    - Tracks a `fail` counter/flag; prints `PASS`/`FAIL` per case (e.g. to stderr or stdout) for readability.
    - At the end: `exit 1` if any case failed, else `exit 0`.
    - Make it executable: `chmod +x test.sh`.
    - Example structure:
      ```bash
      #!/usr/bin/env bash
      fail=0

      check() {
        local desc="$1" expected="$2" actual="$3"
        if [ "$actual" != "$expected" ]; then
          echo "FAIL: $desc — expected '$expected', got '$actual'"
          fail=1
        else
          echo "PASS: $desc"
        fi
      }

      check "no name" "Hello, world!" "$(node greet.js)"
      check "with name" "Hello, Alice!" "$(node greet.js Alice)"
      check "shout" "HELLO, ALICE!" "$(node greet.js Alice --shout)"

      exit $fail
      ```
  - Done when: `bash test.sh` (or `./test.sh` after `chmod +x`) prints three `PASS` lines and exits 0 (`echo $?` shows `0`).
